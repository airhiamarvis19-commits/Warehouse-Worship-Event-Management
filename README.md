# Warehouse Worship – The Gathering 2026

## Event Management & Project Management Case Study

### Overview

This portfolio project analyses Warehouse Worship – The Gathering 2026, a large-scale worship and live music event held in Manchester.

The case study demonstrates how project management principles can be applied to the planning, coordination, delivery and evaluation of a large-scale live event.

The project covers:

- Project planning
- Work Breakdown Structure (WBS)
- Project scheduling
- Budget planning
- Stakeholder management
- Risk management
- Event operations
- Marketing and communications
- Procurement
- Event-day coordination
- KPI development
- Post-event evaluation

## Case Study Disclaimer

This is an independent project-management case study based on publicly available information, event documentation and first-hand attendee observation of Warehouse Worship – The Gathering 2026.

It demonstrates my approach to event planning, project management, stakeholder management, risk management and post-event evaluation.

It does not claim direct involvement in the planning or delivery of the event, nor does it represent internal documentation belonging to the event organiser.

Where internal event information was unavailable, proposed budgets, KPIs, schedules and management processes were developed as illustrative portfolio outputs.

---

## Project Objectives

The project was designed around the following objectives:

1. Develop a structured framework for large-scale event delivery.
2. Identify and manage key project stakeholders.
3. Identify operational and safety risks.
4. Develop an integrated project schedule.
5. Establish an illustrative event budget.
6. Develop an event-day operational plan.
7. Establish measurable project KPIs.
8. Evaluate the attendee experience and identify lessons learned.

## Key Operational Observation

One of the most significant observations from my first-hand attendee experience was congestion during the arrival and entry period.

This highlighted the importance of:

- Peak arrival forecasting
- Entry capacity planning
- Queue monitoring
- Security and steward deployment
- Clear attendee communication

This observation was used as a basis for developing potential project improvements rather than as a judgement of the organiser's overall performance.
